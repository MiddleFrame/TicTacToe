# TicTacToe Plus

Did you ever love Tic-Tac-Toe, but it quickly became predictable? Tired of endless draws?  
Well, we thought so — and turned the classic game into an online collectible card game.

## The main idea

- Play cards to place **X**s and **O**s on the board  
- Collect triples to score points and free up space for new moves  
- Score the most points to win the game  
- Unlock new cards  
- Build decks  
- Repeat until you get bored  

## You can play

- **Against AI**  
  *(like every indie game artist in 2026…)*

- **With a friend on the same device**  
  *(or against yourself, if you’re the only worthy opponent)*

- **Online**  
  *(basically it’s also a game with a friend. What are the chances someone else is searching for a match in this little-known indie game at the same time?)*
